## 域 2 · 工作流设计与任务分发

**审查发现**：分割与并行派发已有，但任务卡无模板、依赖拓扑只有一句话、失败路径不具体、派发无记账。

**深化部署（波次分发模型）**：
1. 任务按依赖分层成**波（wave）**：波内 Agent 单消息并行派发；波间主会话集成验收（编译/测试跑通）+ 重跑监听器刷新 advice；复杂 DAG 用 CreateWorkflow（`subagent_model` 动态传降级链模型）。
2. **任务卡七要素**（模板）：

```
[TC-<项目>-<序号>] 目标：一句话
接口契约：输入 … / 输出 … / 依赖 …（冻结后变更需上报）
验收标准（可执行判据）：测试命令 + 预期输出
文件范围：只允许触碰的路径
难度：S/M/L（hy3-grader 评）
工位：advice 定（岗位 + 链上模型）
状态：pending / in-flight / blocked / done
```

3. **失败矩阵**：失败重试 1 次 → 降级链下一档重派 → 仍失败上报主会话拆任务；攻坚岗两轮无进展必须上报。
4. **派发记账**：每批派发一条事件（工位/模型/任务数）入 events，在途负载可追溯。

## 域 3 · 子智能体头脑风暴

**审查发现**：ideate 岗位有，但视角随口定、产出无沉淀、实例数拍脑袋。

**深化部署**：
1. **标准视角集**（按任务类型选，派发时指定）：架构类=演进性/复杂度/故障面；功能类=体验/边界情况/滥用误用；算法类=正确性/复杂度/数据假设；兜底=反方（专门找茬，必须给反例）。
2. **弹性实例数**（联动 workbuddy 水位，防免费池被打爆）：水位 ≥0.6 → 3 实例；0.3~0.6 → 2 实例；<0.3 → 1 实例串行。
3. **设计决策沉淀（ADR-lite）**：ideate 收敛结论必须写进项目 CONTEXT.md——设计类事件必带收敛结论，头脑风暴不许「聊完就散」。
4. 触发时机三档：接项目方案定型前 / 开发中架构分叉点 / 验收阶段重大权衡复辩。

## 域 4 · 子智能体协助开发工作

**审查发现**：三档工位+降级链+无同文件双写已有；缺协作协议、集成验收、上下文效率设计。

**深化部署**：
1. **契约冻结协议**：分割后接口契约冻结；工位发现契约必须改 → 停手上报主会话，裁决后广播所有受影响工位（依赖单向图）。
2. **波次集成验收**：每波收尾主会话跑集成验证（编译/测试），绿了才放行下一波——拒绝「各写各的最后拼不上」。
3. **scout 前置**：开发工位派发前先派 hy3-scout 出侦察摘要附进任务卡——工位少走弯路，上下文成本大降。
4. **模型目录波动免疫**：链上模型下线自动跳档（监听器校验），目录恢复自动启用；模型变动只改 policy.json。

### v4.2 免费顺位制度（2026-11-04，曼波定）
**需求**：免费模型不止一个，做平行顺位；免费有时效性，失效自动嗅探积分倍率最低的。
**实现**：①网关组 group/free-swarm（routing=free 原生策略，hy3→raccoon 双免费→glm-5.3-flash 兜底，stays=session）挂 base 基础工位群与 grunt；②listener 倍率嗅探：catalog pricing 字段机器可读（prompt/completion 单价），输出 freeModels（实测 5 个：hy3、trae-cn/trae-global 三模型、raccoon sensenova）与 cheapestPaid（auto/glm-5.3-flash 1.2e-7/tok）；③失效自愈闭环：免费模型下架/计价 → pricing≠0 自动移出 freeModels + routing=free 组内自动跳过；新免费模型入目录 → magpie group set free-swarm models+=<id> 纳入。
**语义注意**：routing=free=只用免费成员（含 0.08× 兜底成员会被跳过）；要求纯免费顺位用 routing=order+全免费成员。
**过程 bug**：组别名无 pricing 被误判免费（排除 group/ 前缀）；freeModels 赋值落在写文件之后（顺序修正）；Edit 搬代码块产生两次重复声明（教训：搬代码后 grep 查重名声明）。

### v4.3 优先跨平台（2026-11-04，曼波定：防内部撞车）
**背景**：今天 Trae 线断两次，主线被迫自己动手（不派工位）——单平台押注的风险实证：组内顺位/降级常把主任务和派生工位挤到同一平台，互相拖累还共担断线风险。
**实现**：wave-board `--avoid <平台,..>`（任务声明避开平台）+ `--group <成员,..>`（组内成员清单参与平台集合）；start 第四重检查「平台相撞」：平台集合（model provider+group 成员 provider+avoid）与在途任务相交 → 拦截+处置建议，--cross-platform-ok 放行。
**派发纪律**：主线在 X 平台跑 → 派生工位优先非 X 组/链；主任务 avoid 登记；关键路径不全押单平台。
