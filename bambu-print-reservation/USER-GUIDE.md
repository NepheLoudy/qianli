# 打印预约平台 · 使用手册

> 写给每一位使用打印平台的队员——不含任何代码，只讲「怎么用」。审批人进阶操作看第 4 章，样本录入看第 5 章。网页打不开、状态看不懂，直接翻第 7 章 FAQ；再解决不了群里 @机器人 发 `/print-help` 或找管理员。
> 平台地址：`http://192.168.31.57:3001`（实验室局域网内打开；外网进不了实验室网，这是刻意的安全设计）。

## 1. 账号与登录

1. 打开平台首页，右上角「登录/注册」。**第一位注册的人自动成为管理员**；之后注册需管理员开通（页面会提示联系方式）。
2. 角色分三档，决定你能做什么：

| 角色 | 能做什么 |
| --- | --- |
| member（默认） | 提交预约、看全部单据状态、取消自己的单、复刻自己打过的件 |
| reviewer（审批人） | member 全部 + 审批通过/驳回、人工恢复卡住的任务、规则治理面板 |
| admin（管理员） | reviewer 全部 + 用户管理、打印机控制（暂停/停止）、状态强改 |

3. **绑定飞书通知（强烈建议）**：页面右上「🔔 飞书通知」生成 6 位绑定码（5 分钟有效），然后在飞书里 @打印机器人 或私聊它发送 `/print-bind 绑定码`。绑定成功后，你的单据每一步变化（通过/驳回/完成/失败/取消）都会**私信**通知你——不绑定也能用，只是得自己刷网页。

## 2. 提交一个打印任务（普通队员核心操作）

### 2.1 两种提交路径，先分清你手里有什么

| 你手里的文件 | 走哪条路 | 谁定切片参数 |
| --- | --- | --- |
| **已经切好的** 3mf / .gcode.3mf（Bambu Studio / Orca / FlashPrint「导出切片文件」；**纯 .gcode/.gx/.g 不再接受**，2026-11-06 起两品牌统一封死） | 直接上传切片文件 | 你自己（切片时已定），系统原样分发 |
| **还没切的** STEP / STL（CAD 源文件） | 上传源文件 + 勾选工况需求 | 系统自动切片（规则库 + 学习模型按你的工况定参数） |

> 文件上限 200MB。份数：源文件单支持多份，多份会**盘内排版一次成型**（不是打完一盘再打一盘，速度最快）；**切片直通件份数固定 1**（v98 起：多份请在切片软件里排盘，或打完用「复刻」再打一盘）。
> **一盘多件**：手里是一份切片+一堆 CAD 源文件（同一盘里打了多个模型）？提交/审批时源文件可以**多选**（最多 12 个），系统按几何指纹自动配对「切片里哪个 object 是哪件」，逐件入库与回填——三个长得一样的件也会如实告诉你「配对不可信」。

### 2.2 表单逐项说明

- **材料**：切片直通单不用填（文件里已带）；源文件单**可以不填**——你勾的工况需求（耐温、绝缘、柔性……）会让系统自动排除/偏好合适材料，填了则作为校验。颜色决定用哪台机的哪个料盘，尽量从下拉选（自由文本可能匹配不到颜色）。
- **份数 / 加急**：加急的排队优先级更高（切片直通单在表单勾「加急」，源文件单勾「高速打印」标签会联动加急）。
- **指定打印机**（可选）：留空 = 系统按材料自动选机。指定了就必须是登记清单里的名字，填错当场打回。
- **工况勾选（源文件单的关键步骤）**：
  - **不勾任何项 = 常规件**，直接提交也完全可以；
  - **受力方向**按「这件**工作时**的朝向」勾（Z=工作时竖直向上）——不是打印摆放方向，系统会据此决定打印朝向和层间强化；
  - 常用项：外观件（表面要好看）、配合件（要跟别的零件装配）、重载/冲击、耐温、电气绝缘（会强制排除碳纤——碳纤导电）、柔性件、重量敏感（无人机件）；
  - **几何体检自动勾选**：上传源文件后系统自动分析模型，检出通孔/重悬空/大曲面/小底面会预勾选对应标签——**可以改**，你比算法清楚哪些孔真的重要；
  - 有硬冲突的组合（比如耐温 80°C × PLA、绝缘 × 碳纤）会在提交时**当场打回**并说明原因，改勾选即可。

### 2.3 提交之后会发生什么

```
待审批 →（审批人通过）→ 排队中 → 打印中 → 已完成
   ↘ 驳回 / 你主动取消（任意时刻可取消）
```

- 源文件单在**审批通过后、轮到它打印时**才自动切片（按审批时锁定的参数），切完直接上传开打。
- 完成后你会收到**私信**，里面带 **6 位取件码**——到实验室取走打印件，然后在**同一条私信**里回复 `/print-pickup 取件码`，系统确认后清理打印机并放行队列里的下一件；页面「我的单据」上也有「确认取件」按钮，效果相同。**谁都能帮确认**（v99 起：实验室公共空间，任何登录用户看到件已取走都可点确认，回执人如实记录）；**24 小时无人确认会自动放行该机开打下一件**（自动放行≠件已取走，开新件前请人工看一眼台板防撞板）。
- **多份任务**：每盘打完都会走一次「私信通知 → 取件确认」循环，确认一盘才打下一盘。

### 2.4 其他常用操作（都在「我的单据」列表）

- **取消**：排队中/打印中都能取消（打印中取消系统会下发停机指令）。
- **复刻**：已完成单上的「复刻」按钮——带原参数一键重提，源文件不用重新传（需求单会按当前规则库重新定档）。

## 4. 审批人操作（reviewer+）

登录后进「审批台」（导航栏切换），待审批单每 15 秒自动刷新。

### 4.1 一张审批卡上有什么

- **需求/文件/发起人**基本信息，**参数**（这单会怎么切：层高/填充/支撑…）、**依据**（命中了哪些规则及理由）；
- **🧠 模型行**（如果参数智能层已启用）：显示学习模型的修正值或影子建议，含置信度百分比——置信度低于门限的参数自动保持规则值，不会装懂；
- **初审警告**：提交时已预检过机队有无同型号机、机端有无对应耗材——警告只提示不拦截；
- 3mf 直通单会显示**内嵌参数摘要**（不用下载文件开切片软件就能核对）。

### 4.2 预览弹窗（点卡片进入）

- **网格预览**：3D 渲染模型（可拖转）；
- **刀轨截面**：切片产物按 Z 层逐层查看真实挤出路徑——核对支撑/摆放最直观；
- **切片回读校验**：专家切片参数 vs 引擎参数逐项对比，给加权拟合度百分比；差异项说明规则库还没覆盖这个 case，可一键转候选规则。

### 4.3 通过 / 驳回

- 通过时可选**指定打印机 / AMS 槽位 / 喷嘴**（都不填 = 自动匹配）；
- **「入库训练样本」勾选**（重要）：勾上后这单完成/失败会自动写进样本库——**审批做两件事：决定能不能打 + 决定要不要进训练集**；
- 驳回需填理由（会私信通知申请人）。

### 4.4 日常维护

- **放弃池黄条**：自动重试耗尽的任务停在这里，选台打印机一键「人工恢复」；
- **规则治理面板**（训练台页 reviewer 区）：「从样本库拟合规则」跑统计、待审池采纳/拒绝修正建议、🧠 参数智能层训练与采纳（先影子模式观察、点头后切生效）——采纳前看逐参数 LOFO 误差表，数字不好看的别采纳。

## 5. 样本录入（训练台，面向愿意喂样本的队员）

样本 = **模型文件（自动提几何特征）× 工况勾选（人工标注）× 已切片产物（自动提专家参数）**三方合成，录入即入库、无审批。

1. 训练台页上传模型（STEP/STL/3mf）+ 切片产物，勾工况（≥1 项强制）；**一次可选最多 12 个模型**（一盘多件批量录入）——系统按几何指纹自动配对每件归属，入库结果逐条列出「#样本号 ← 文件名（盘内件 #N）」；
2. **拟合度条**会实时显示「引擎按工况算的参数」与「专家切片参数」的贴合度——差异大的项就是规则库没学会的，最有录入价值；
3. 复杂工况可以进 **3D 标注工房**：在模型表面直接点「这里受弯 / 这里是接触面 / 这里要外观」，比勾选标签精确得多；
4. 打印完成后记得回样本库**标结果（成功/失败）**——失败样本是学习回路最值钱的信号。

## 6. 观察台（谁都可以看）

导航栏「设备观察台」：全机队卡片（状态/进度/温度/AMS 料盘）、实时画面（拓竹/闪铸都在线看）、文件管理；admin 有暂停/恢复/腔灯/停止按钮。预约中心右侧还有个**机队悬浮坞**，任何页面都能瞄一眼每台机在干嘛。

## 7. FAQ（状态解读与常见问题）

**Q：为什么我的单一直在「排队中」？**
按顺序排查：①加急的人在你前面；②目标材料所有机都在打/料盘缺料（`/print-ams` 看料）；③上一单打完在等**取件回执**（同型号机都在挂闸时本单排队等放行——确认取件、或挂闸满 24 小时自动放行后即开打）；④缺料提醒已发过的话系统每 30 分钟才会再提醒一次。

**Q：提交被打回「勾选存在硬冲突」？**
你勾的工况组合在物理上矛盾（例：耐温 80°C×PLA 会在 60°C 软化；电气绝缘×碳纤导电）。按打回说明改勾选即可。

**Q：晚上提交怎么群里没动静？**
**02:00–09:00 是播报静默期**：群卡片不播（不补发），私信通知会积压到 09:00 一起补，打印本身和网页/指令不受任何影响。

**Q：显示「失败」了怎么办？**
系统已自动取证并重试（最多 3 次；被判确定性失败的——如工程 3mf 分发闸拦截——不重试直接终局）；重试耗尽会进「放弃池」并私信你。如果被判定为「人工取消」但你没取消过，找审批人看失败码——断料/堵料等真故障带机器上报证据，不会冤枉你。

**Q：打出来的件是反的/孔插不进？**
立即反馈审批人。源文件单检查：①受力方向是不是按工作朝向勾的；②配合件有没有勾对应标签（系统会给孔径补偿）；③Place on Face 手动摆放过的优先级最高。带 3D 标注重提一单，标注越具体修得越准。

**Q：我传的 STEP 显示「特征分析不可用」？**
多半是模型太复杂（超过 60 万面片）——回 CAD 降低细分精度再导出。

**Q：想打材料库里没有的料？**
指定打印机会因耗材不匹配一直排不上。先 `/print-ams` 看现在装了什么，选系统有的材料，或找管理员换料。
