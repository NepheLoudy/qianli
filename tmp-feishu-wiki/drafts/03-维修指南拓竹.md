# 3D打印机维修指南（拓竹）

> 遇到报错请先在此指南中搜寻，节约他人时间；处理不了再找打印机维护员。
> **维护员**：张博洋（老登）、郭禹澄、陈夏菲、张郭浩（AAA竹子维修）
> 原框架：张博洋；2026-11-06 扩写。

## 维修前的三件事

1. **先看机器屏幕**：拓竹四机（H2D/X1C/P1S/A1 mini）屏幕会直接显示故障码与文字提示，截图保存——报错记录要用。
2. **官方 Wiki 先查**：https://wiki.bambulab.com/zh/home ——大部分报错按步骤走基本能解决；Wiki 上找不到的去 B 站搜机器型号+故障现象。
3. **判断能不能自己动**：**只有换耗材、清热床残料、重启机器**可以自己做；凡是要拆喷嘴、拆热端、动皮带/导轨、动 AMS 内部、动主板——拍照留证后找维护员，不要自己拆。

## 基本结构

拓竹系结构大同小异，认识这几个部件就够排查用：

| 部件 | 干什么的 | 排查时看什么 |
| --- | --- | --- |
| 热端（喷嘴+喉管+加热块） | 把耗材熔化挤出 | 堵料/漏料/温度报错 |
| 挤出机（挤出轮） | 把耗材推进热端 | 打滑磨料（料上出现齿痕但不出料） |
| 烧结玻璃/PEI 热床 | 承载打印、提供附着 | 首层不粘/残留胶渍 |
| 碳纤导轨 X/Z 轴 | 运动精度 | 丢步/异响/层错位 |
| AMS/AMS lite 料盘槽 | 自动供料与换色 | 进料提示（RFID 识别不到/进料卡住） |
| 屏幕/摄像头 | 状态显示与观察 | 故障码、远程画面确认故障现象 |

## 常见故障速查表

| 现象 | 最可能原因 | 处理 |
| --- | --- | --- |
| 预约系统显示「故障」或卡片变红 | 机器上报了故障状态 | 先看屏幕故障码，对照速查表处理，处理后观察台看状态是否恢复 |
| 打印中突然停了，屏显 HC/ heater err 类 | 热端/热床加热故障（N100/热敏/加热棒） | **找维护员**，自己处理不了 |
| 打印中断料 | 料盘见底/料打结/进料通道卡 | 换料盘（见下「换料」），断点从 AMS 通道里退出残料重进 |
| 打印中堵头 | 频繁换料残料碳化/温度不符 | 找维护员通喷嘴，不要自己捅针猛捅 |
| 首层不粘/局部粘局部翘 | 残留指纹油/胶渍、Z 偏移不当 | PEI 板用异丙醇（IPA）擦热床；仍不粘报维护员调 Z 偏移 |
| 件打完粘死在热床上取不下 | 首层附着过强 | 把热床升到 55~60°C 软化后取；别用金属铲硬撬 PEI 板 |
| AMS 进料卡住 | 料头切角不对/通道残料 | 把料头斜剪 45° 重试；仍卡住找维护员 |
| 掉网/机器在预约系统显示未连接 | 机器 WiFi 掉线或 DHCP 情况变化 | 重启机器，仍不掉才查路由；恢复后通知管理员在观察台确认回连 |
| 群里机器人播报「跨品牌误派」事故复现 | 切片时打印机型号选错 | 按新规重切（见《3D打印机预约系统》机型锁定一节），并把误派件从机器上取下 |

## 分机型注意点

### H2D（双喷头）

- 双喷头机型切片时**喷嘴选择要一致**：预约单可选自动/指定喷嘴，切片时用哪个喷嘴切就锁定哪个。
- H2D 只认工程 3mf 里带切片数据的件，**裸 3mf（无 plate gcode）会直接失败**——切片器导出「切片文件」而不是工程文件。
- 摄像头等「清屏弹窗」类机端弹窗会挡机端操作，必要时远程/线下清弹窗。

### X1C / P1S

- **料信息远程写入**：管理员可从观察台远程写入料信息（回执+状态回读双重验证）——线下换料时请先线下确认料盘，再让管理员同步。
- P1S 上传走 FTPS 990（新固件已关 21 明文口）；A1 mini 走同一 FTPS 通道，规则同 P1S。
- **固件更新要谨慎**：新固件可能改端口/协议行为（2026-10-07 实测新固件关闭 21 明文口），升级前群里说一声，避免预约系统分发链路受影响。

### A1 mini

- 结构轻量，**震动/摔碰对打印质量影响明显**，放置台面要稳；
- 打印完成取件后热床会回落，**取件时注意热床还热**。

### 闪铸 AD5M Pro / Creator 5 Pro（预约系统内闪铸两台）

- 屏幕必须开「LAN Only 模式」预约系统才能连（RAM 情况下机器连云了预约系统就够不着）；
- **打印完成后的机端弹窗会挡控制**——观察台 admin 有「🧹 清屏弹窗」按钮，线下也直接点屏幕清除；
- 闪铸固件 5.1.9 **拒绝远程暂停/停止**（远程指令免疫），要停机**直接按机端屏幕停止**；直接 cancel 同一单会重打，按屏幕停止后通知管理员在预约系统取消单据；
- C5P（四喷头）切片时喷嘴选择与 H2D 同理。

## 报错记录（写工单）

机器报错处理完（或处理不了转维护员）都要**留痕**——按下面模板追加到本节（直接在文档里加编号续写）：

```
### 报错N · 日期 · 机器 · 报错人
- 故障现象：
- 故障码/屏显信息：
- 复现条件（哪个任务/什么工况）：
- 处理过程：
- 结果（已解决/转维护员/待观察）：
- 经验（下次遇到怎么办）：
```

### 报错一 · 2026-11-06 · 拓竹 H2D · 记录人：管理员（示例）

- 故障现象：提交的纯 .gcode 直通单下发后秒失败（屏显 84033581 找不到任务数据）
- 故障码：84033581
- 复现条件：OrcaSlicer 按 H2D 切纯 .gcode 直通提交（机型锁定新规之前的旧提交方式）
- 处理过程：远程试发同单 FAILED 后全指令免疫挂死，断电重启恢复
- 结果：已解决——按新规导出 .gcode.3mf 后不再复现；系统已强制机型锁定校验
- 经验：拓竹机只吃「导出的切片文件」（.gcode.3mf），纯 gcode 只能发闪铸
