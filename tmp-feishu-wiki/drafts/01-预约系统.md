## 2. 提交打印任务（队员核心操作）

### 2.1 两种提交路径，先分清你手里有什么

| 你手里的文件 | 走哪条路 | 谁定切片参数 |
| --- | --- | --- |
| **已经切好的** 3mf 或 gcode/gx（Bambu Studio / OrcaSlicer / FlashPrint 导出） | 直接上传切片文件 | 你自己（切片时已定），系统原样分发 |
| **还没切的** STEP / STL（CAD 源文件） | 上传源文件 + 勾选工况需求 | 系统自动切片（规则库 + 学习模型按你的工况定参数） |

- 文件上限 **200MB**。
- 两种路径都支持「份数」：多份会**盘内排版一次成型**（不是打完一盘再打一盘）。
- **一盘多件**：一份切片 + 多个 CAD 源文件（同一盘打了多个模型）时，源文件可**多选**（最多 12 个），系统按几何指纹自动配对「切片里哪个 object 是哪件」，配对不可信时会如实提示。

### 2.2 切片件机型锁定（重要！2026-11-06 新规）

系统按切片文件**内嵌的机型指纹**锁定可派打印机，防止「A 机器的切片拿给 B 机器打」的跨品牌废件事故：

1. **切片时务必先选对打印机型号**——OrcaSlicer / Bambu Studio 里打印机配置选实际会接单的那台（如拓竹 P1S / 闪铸 AD5M Pro）。
2. 上传时系统会**自动识别机型并锁定**：页面提示「允许机名单」，不在名单里的机器无法被这单派到。
3. **拓竹机只能吃「导出的切片文件」（.gcode.3mf）**——直接导出纯 .gcode 拓竹机不认，会打失败；
4. **纯 .gcode / .gx / .g 只能指定闪铸机型**。
5. 没有指纹的切片文件会被系统拦下转人工审批，不会瞎派。

### 2.3 表单逐项说明

| 字段 | 怎么填 |
| --- | --- |
| **使用场景**（必填） | 九选一：测试迭代件 / 基础建设件 / 机器人项目件 / 承力结构件 / 夹具·工装件 / 电子/设备外壳件 / 外观·展示件 / 教学演示件 / 备件·替换件 |
| **材料** | 可不填（按工况自动反推）。可选：PLA / PLA-CF / PETG / PETG-CF / ABS / ASA / PA / PA-CF / PC / TPU / PVA 等。切片直通单不用填（文件里已带） |
| **颜色** | 从下拉选（白色/黑色/红色/蓝色/绿色/黄色/灰色/橙色/紫色/粉色/棕色/透明/银色/金色），自由文本可能匹配不到料盘；多色件用「+」连接（如 白色+黑色）并勾「多色打印」 |
| **份数** | 1–99。多份会盘内排版一次成型 |
| **指定打印机** | 可留空 = 系统按材料自动选机。切片文件会被机型指纹锁定，只能选同型号机 |
| **模型/切片文件** | 接受 .stl / .step / .3mf / .obj / .gcode / .gx / .g，上限 200MB |

**工况标签勾选（源文件单的核心步骤）**，按组分类：

- **载荷工况**：受力方向（X/Y/Z/多向拟合）——Z=工作时竖直向上，按**工作朝向**勾而不是打印摆放；受力类型（拉/压/剪切/弯曲/扭转）；载荷性质（静载/疲劳/冲击/振动）；量级（轻/中/重载）
- **耐久工况**：使用寿命（一次性/赛季内/上场件）、电气绝缘（强制排除碳纤——碳纤导电）、失效后果、反复拆装
- **精度与连接**：配合需求（间隙/过盈/精密公差）、连接方式（自攻螺钉/机制螺栓/热熔铜螺母/胶接）、关键公差
- **热学工况**：耐温等级（常温≤50°C / 中温 50–80°C / 更高档）、隔热、阻燃
- **材料特性 / 环境**：自润滑、含纤维增强、耐磨；耐油、户外 UV、防水、粉尘
- **效率/重量**：快速模式（联动加急）、重量敏感（无人机件）
- **外观**：外观件、多色打印、透光件

三个加分功能：

1. **几何体检自动勾选**：上传源文件后系统自动分析模型，检出通孔/悬空/大曲面/小底面会预勾对应标签——**可以改**，你比算法清楚哪些孔真的重要；
2. **3D 工况标注工坊**：直接在模型上点标注——悬空需支撑、受弯轴线、载荷箭头（受力类型/方向/量级）、接触面、外观面；还有「放置平面」可以指定打印朝向；
3. **切片直通补源文件**：提交切片文件时会弹「有这个件的 STEP/STL 源文件吗？」——传了源文件不打印、只进训练库，让系统切片越学越准。

有硬冲突的组合（比如耐温 80°C × PLA、绝缘 × 碳纤）会在提交时**当场打回**并说明原因，改勾选即可。

### 2.4 提交之后会发生什么

```
待审批 →（审批通过）→ 排队中 → 打印中 → 已完成
   ↘ 驳回 / 你主动取消（任意时刻可取消）
```

- 开启自动分发的时期，提交后系统直接**自动通过入队**（等同审批通过），审批台降级为复核干预面板；你只需要等排队。
- 源文件单在**轮到它打印时**才自动切片（按审批时锁定的参数），切完直接上传开打。
- 完成后你会收到**私信**，里面带 **6 位取件码**——到实验室取走打印件，然后在**同一条私信**里回复 `/print-pickup 取件码`，系统确认后清理打印机并放行下一单。24 小时内有效；页面「我的单据」上也有「确认取件」按钮，效果相同。
- **多份任务**：每盘打完都会走一次「私信通知 → 取件确认」循环，确认一盘才打下一盘。

## 4. 审批人操作（reviewer+）

登录后进「审批台」（导航栏切换），待审批单每 15 秒自动刷新。自动分发开启时这里是**复核干预面板**：新单提交即自动入队，待审批列表只出现**自动选机失败转人工**的单。

- **一张审批卡**：需求/文件/发起人、规则引擎参数、判定依据、3mf 直通单的内嵌参数摘要、轨迹。
- **通过时**可选指定打印机 / AMS 槽位 / 喷嘴（都不选 = 自动匹配）；换料后点「🔄 AMS 同步」让拓竹机重推料盘。
- **预览 / 切片核对弹窗**：3D 网格预览（可拖转）、刀轨截面（按 Z 层看真实挤出路徑，核对支撑/摆放）、自动切片预览（机型×份数排盘）。
- **单据总览**：全量单据按状态筛选、搜索、分页，行内可详情/复刻/取消；「复刻」带原参数一键重提。
- **进行中**：异常时可改派（人工直发）/取消（打印中会下发停机指令）。
- **放弃池**：自动重试耗尽的任务停在这里（黄色横条），选台打印机一键「人工恢复」或丢弃。

## 7. FAQ

**Q：为什么我的单一直在「排队中」？**
按顺序排查：①加急的人在你前面；②目标材料所有机都在打/料盘缺料（`/print-ams` 看料）；③上一单打完在等**取件回执**（机器挂着取件闸，确认取件才放行下一单）；④缺料提醒 30 分钟内不会重复发。

**Q：提交被打回「勾选存在硬冲突」？**
你勾的工况组合在物理上矛盾（例：耐温 80°C×PLA 会在 60°C 软化；电气绝缘×碳纤导电）。按打回说明改勾选即可。

**Q：晚上提交怎么群里没动静？**
**02:00–09:00 是播报静默期**：群卡片不播，私信通知会积压到 09:00 一起补，打印本身和网页/指令不受任何影响。

**Q：显示「失败」了怎么办？**
系统已自动取证并重试（最多 3 次）；重试耗尽会进「放弃池」并私信你。如果被判定为「人工取消」但你没取消过，找审批人看失败码——断料/堵料等真故障带机器上报证据。

**Q：打出来的件是反的/孔插不进？**
立即反馈审批人。源文件单检查：①受力方向是不是按工作朝向勾的；②配合件有没有勾对应标签；③手动摆放过的（Place on Face）优先级最高。带 3D 标注重提一单，标注越具体修得越准。

**Q：我传的 STEP 显示「特征分析不可用」？**
多半是模型太复杂（超过 60 万面片）——回 CAD 降低细分精度再导出。

**Q：想打材料库里没有的料？**
指定打印机会因耗材不匹配一直排不上。先 `/print-ams` 看现在装了什么，选系统有的材料，或找管理员换料。

**Q：切片文件提交被拦「未识别到机型指纹」？**
你的切片文件里没带机型信息（老版本切片器导出或改过名）。用 OrcaSlicer 重切一遍，确认打印机配置选对了再导出；有急用就提交后找审批人人工指定机型。
