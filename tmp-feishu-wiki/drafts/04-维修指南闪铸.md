> 遇到报错请先在此指南中搜寻，节约他人时间；处理不了再找打印机维护员。

## 维修前的三件事

1. **先看机器屏幕**：故障码/弹窗信息截图保存；闪铸完成打印后**屏幕会弹完成弹窗**——这个弹窗不清掉会挡住后续一切机端操作（预约系统的远程控制也会被挡），线下直接点掉，远程让管理员在观察台点「🧹 清屏弹窗」。
2. **官方支持先查**：闪铸官网支持中心（flashforge.com → Support）按机型搜 FAQ；找不到的去 B 站搜「闪铸 AD5M / Creator 5 Pro + 故障现象」。
3. **判断能不能自己动**：只有**换料、清平台残料、按屏幕停止/取消任务、重启机器**可以自己做；拆喷嘴、拆热端、动导轨/皮带——找维护员。

## 预约系统联动必须知道的事

1. **LAN Only 模式必须开**：机器屏幕设置里开启「局域网模式（LAN Only）」预约系统才能连上它；机器连回云模式预约系统就够不着了，状态会显示「未连接/失联」。
2. **固件 5.1.9 拒绝远程暂停/停止**：预约系统/观察台发的远程暂停/停止指令闪铸机端**不执行**（指令免疫）——要停机**直接按机端屏幕**停止；停完后通知管理员在预约系统里取消对应单据。
3. **不要在机端重复取消同一单**：机端直接 cancel 同一任务可能触发自动重打（机端取消后指纹是 canceling，系统会按人工取消处理，但机端残留任务要确认清掉）；**停机后看一眼屏幕任务列表是否清空**。
4. **断电重启是万能兜底**：远程指令全免疫/画面代理卡死（8080 通道半死不活）时，直接断电重开——恢复后预约系统 15~30 秒内自动回连。

## 常见故障速查表

| 现象 | 最可能原因 | 处理 |
| --- | --- | --- |
| 预约系统显示「未连接/失联」 | LAN Only 被关了 / 机器断网 / 弹窗挡屏 | 检查屏幕 LAN 设置、点掉弹窗、重启机器 |
| 远程暂停/停止没反应 | 固件 5.1.9 特性，远程指令免疫 | **按机端屏幕停止**，别反复发远程指令 |
| 打印完成后机器不动、预约系统也不放行下一单 | 完成弹窗没清 / 等取件回执 | 线下取件并在私信回复取件码（见预约系统文档）；弹窗点掉 |
| 进料卡住/送料异响 | 料头切角不对、料仓里料打结 | 料头斜剪 45° 重进料；整理料仓余料 |
| 首层不粘 | 平台残胶/油污、调平偏移 | 平台清理（乙醇擦拭）；跑一次机端自动调平（光敏标定） |
| 堵头 | 换料残料碳化、降温拆料拉丝 | 找维护员通喷嘴 |
| 打完的件粘死在平台 | 平台还热附着强 | 等平台冷却后取（柔性平台可取下弯折脱件） |
| 预约系统画面卡死不出图 | 8080 画面通道半死 | 等一会儿/刷新；仍不行断电重启机器 |
| C5P 四喷头任务用错喷嘴 | 切片时喷嘴选择与实际不符 | 重切，确认切片器里选对喷头；转维护员核对 |

## 与拓竹机的差异速记（从拓竹转过来的同学看）

| 维度 | 拓竹系 | 闪铸系 |
| --- | --- | --- |
| 多色 | AMS 自动换色 | A5P 单色；C5P 靠多喷头 |
| 远程停止 | 支持 | **不支持**（按屏幕） |
| 完成弹窗 | 无此问题 | **会挡控制**，记得清 |
| 接入方式 | MQTT+SFTP/FTPS | HTTP 局域网（必须 LAN Only） |
| 耗材匹配 | AMS 料盘（槽位/颜色） | 单料仓（按克数余量） |

### 报错一 · 2026-10 · 闪铸A5P · 记录人：管理员（示例）

- 故障现象：拓竹切片误派到 A5P 开打（跨品牌废件），远程停止无效，打完后机端自动重打
- 故障码：无（固件 5.1.9 远程停机免疫）
- 复现条件：机型锁定新规上线前的旧提交方式（纯 .gcode 直通单被误派）
- 处理过程：按屏幕停止 → 清任务残留 → 断电重启 → 系统回连正常
- 结果：已解决——系统已强制机型锁定，此类误派不再发生
- 经验：闪铸要停机永远按屏幕；跨品牌废件先断电止损再排查队列
